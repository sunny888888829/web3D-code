About the Project

Deeper Understanding: Shaders

Implemented custom GLSL Vertex and Fragment shaders to achieve a 'Fresnel' rim-lighting effect. This allows the models to have a vibrant, 'refreshing' glow that reacts to the camera's viewing angle, simulating high-end studio lighting.

  • Custom Material: THREE.ShaderMaterial implementation.
  • GLSL: Native vertex/fragment code for optimized rendering.

Post-Processing Pipeline

Utilized the EffectComposer to create a cinematic rendering pipeline:

  • UnrealBloomPass: Adds a soft glow to bright surfaces, creating a premium metallic and glass look.
  • Reinhard Tone Mapping: Ensures high dynamic range (HDR) colors are correctly mapped to the screen.

Advanced Architecture: MVC & AJAX Pipeline

This application implements a professional Model-View-Controller (MVC) architectural pattern, demonstrating a deep understanding of modern web engineering:

  • Model (JSON/AJAX): All 3D model metadata is stored in an external models.json file. Data is fetched asynchronously via an AJAX (fetch API) pipeline, ensuring the UI stays responsive.
  • View (Three.js/Bootstrap): The viewer utilizes a dual rendering strategy (Standard WebGL + EffectComposer Post-processing) to display high-fidelity results.
  • Controller (Vanilla JS): Centralized event delegation and state management coordinate the data loading, camera transitions, and shader parameter updates.
