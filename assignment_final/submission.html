Environment & How to Run

This project does not require npm, build tools, or package installation for normal viewing. It is best viewed locally with VS Code Live Server or another local HTTP server so that models.json, GLB models, MP3 audio, and MP4 video load correctly.

Recommended: open the project folder in VS Code, right-click index.html, and choose Open with Live Server.

cd "/path/to/your/Web 3D code"
python3 -m http.server 8000

Open http://127.0.0.1:8000/index.html in a modern WebGL-enabled browser such as Chrome, Edge, Firefox, or Safari. Internet access is recommended for the Bootstrap, Font Awesome, Google Fonts, and Three.js CDN libraries.

Statement of Originality & Advanced Features

The project implements a responsive mobile-first Bootstrap site with a Three.js WebGL viewer, JSON/AJAX model metadata, local media assets, generated video, embedded GLB cameras, and source archive deliverables.

  • MVC/Data Pipeline: Model data is loaded from assets/data/models.json.
  • 3D Assets: Three GLB models are loaded from assets/models/.
  • Interaction: Wireframe, lighting, camera views, animation clips, and sound are controlled in js/app.js.
  • Media: Gallery images and the promotional video are local project assets.
