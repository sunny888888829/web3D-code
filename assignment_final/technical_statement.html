Project: MyBrand Premium 3D Beverages

Author: HONGQUAN CHEN

Technical focus: WebGL rendering, JSON data loading, GLB cameras, animation, audio, and responsive Bootstrap layout.

1. MVC & Data Pipeline

The app separates model metadata from the view by loading assets/data/models.json with the Fetch API. The Web3DApp controller manages model selection, description updates, camera changes, lighting controls, audio loading, and animation playback.

2. Three.js Rendering

The viewer uses Three.js, GLTFLoader, OrbitControls, lights, optional post-processing, and responsive resize handling. GLB assets are scaled and framed automatically using mesh bounds so the viewer works across screen sizes.

3. Cameras, Audio & Animation

  • Each GLB has embedded camera nodes that match the model metadata.
  • Model-specific camera buttons move to front, top, side, and model views.
  • GLB clips are played through THREE.AnimationMixer and clipAction.
  • Each model has a local audio file loaded through THREE.AudioLoader.

4. Local Media & Submission Readiness

Images, audio, GLB files, metadata, source archives, and the promotional video are all local project assets. This avoids broken external project links during marking.
