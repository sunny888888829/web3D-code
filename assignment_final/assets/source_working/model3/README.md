# Recycled Crushed Can Source Archive

This package is the original-project archive deliverable for model3. It contains the exported GLB, camera metadata, audio reference, and modeling notes used by the Three.js application.

Native .blend and .max files cannot be generated truthfully on this machine because Blender and Autodesk 3ds Max are not installed. The included GLB is the editable/interchange scene asset used by the web application, with cameras now embedded into the GLB JSON chunk.

- source_manifest.json
- README.md
- native_project_note.blend.txt
